## Homelab
 
The place where I practise what I don't get to touch at work.
 
- **Infrastructure:** UGREEN NAS plus a Lenovo ThinkCentre, with the Docker stacks managed in Portainer
- **Observability:** Grafana LGTM stack (Loki, Mimir, Tempo, OpenTelemetry Collector) with node-exporter and cAdvisor
- **Security:** CrowdSec with GeoIP enrichment, public apps behind Cloudflare Tunnel and Nginx Proxy Manager, admin services reachable only over Tailscale
- **Data:** one shared SQL Server instance with a separate login per app
- **Services:** Jellyfin, Vaultwarden, Homepage and more
